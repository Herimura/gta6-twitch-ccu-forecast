Hour-by-hour forecast of GTA VI's launch-day Twitch viewers. `main.py` (Python, standard library only, deterministic) projects a launch's hour-1 viewer print along similarity-weighted empirical quantile curves of comparable launches' log-ratio trajectories, blended toward a parametric curve fitted to the weighted median (log-hour polynomial plus release-wave bumps), with the spread calibrated around the median. It reads a case JSON on stdin and prints the hourly forecast JSON on stdout.

## Run it

```sh
python3 main.py < case.json > forecast.json
```
